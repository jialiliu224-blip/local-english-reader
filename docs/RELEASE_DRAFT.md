# 0.8.0 源码预览版 · 版本说明

Local English Reader：为中文 Python / AI 学习者准备的 macOS 英文选区朗读小工具。

选中英文，按 Option+Esc；本机 Qwen3-TTS 使用你自行配置的声音朗读，结束后显示 1—5 条简短中文词义。句子使用已安装的 Apple 翻译资源。无需云端语音 API Key。

本次仅发布源代码。需要 Apple Silicon、macOS 26+、Swift 编译环境、Python 及本地模型；尚无一键安装包、Developer ID 签名或公证。未附带作者的声音或个人数据。

已经验证：源码构建、现有逻辑测试与新增配置检查。尚待验证：另一台 Mac 全新依赖安装、自己的声音配置、完整播放和跨应用快捷键。
