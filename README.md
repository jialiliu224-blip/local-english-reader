# Local English Reader

选中英文，按 **Option（⌥）+ Esc**，用自己配置的本机声音朗读；读完显示简短中文释义。面向正在学习 Python / AI 英语的中文使用者。

这是早期源码版本，需要手动配置 Python 和本地语音模型。可以把仓库交给 Agent，按 [AGENTS.md](AGENTS.md) 协助本机部署。项目不附带作者的声音、录音、声纹、模型权重或个人配置。

## 能做什么

- 全局快捷键触发；从当前应用的辅助功能接口读取选区，不模拟复制、不扫描整页。
- 英文自动朗读，结束后出现不抢焦点的小卡片；中文不朗读。
- 单词显示 1—5 条核心中文意思，Python / AI 用义优先；不显示拼音或例句。排序是学习相关性，不是使用频率统计。
- 短语和句子通过 Apple Translation 本机翻译。
- 本地 Qwen3-TTS 模型预热，重复文本音频保存在有上限的内存缓存中。

## 系统要求与验证范围

- Apple Silicon Mac；构建目标 **macOS 26.0+**，需要可用的 Swift 编译工具和 macOS SDK。
- Python 3.11 环境及 `requirements.txt` 中的依赖。依赖版本来自已有工作环境，尚未在全新机器完成安装验收；不是完整依赖锁文件。
- 自行准备本地 MLX 格式 Qwen3-TTS Base 模型、本人或已获许可的参考录音及其准确文字。
- Apple 的英语（英国）→ 简体中文翻译资源；普通单词的补充释义取决于本机已安装的英汉词典。
- 本项目已做本机编译和逻辑测试；公开配置版本尚未做第二台 Mac 的完整语音及快捷键验收。不承诺所有应用都提供选区。

## 构建

在项目根目录运行：

```sh
zsh scripts/test.sh
zsh scripts/build.sh
```

产物位于 `build/Local English Reader.app`。脚本只构建和本地临时签名，不安装 App、不修改系统设置、不自动下载模型。此版本未做 Developer ID 签名或 Apple 公证。

## 配置自己的声音

1. 使用自行管理的 Python 3.11 虚拟环境安装依赖：`python -m pip install -r requirements.txt`。安装会联网下载依赖，可能占用较多磁盘空间；不要替换系统 Python。
2. 按 [MLX 模型卡](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-Base-8bit) 的说明，自行下载该 Base 模型到本地。运行阅读器时强制 Hugging Face 离线模式，不能用远程模型名称代替本地目录。
3. 将 `voice.example.json` 复制到 `~/Library/Application Support/LocalEnglishReader/voice.json`，自行创建所需父目录。
4. 填入 Python 可执行文件、模型目录、自己的参考录音的绝对路径，以及录音的准确文字。占位内容无法用于朗读。建议配置文件仅允许本人读写（权限 600），声音素材放在仓库之外。

不要把真实 `voice.json`、录音、生成音频、模型文件或私人路径提交到 Git。忽略规则只能防止部分误操作，不能代替发布前检查。

## 首次使用

1. 将自己构建的 App 放到固定位置后打开。阅读器保持后台运行，菜单栏显示“读”。
2. 在系统设置 → 隐私与安全性 → 辅助功能中，为该 App 开启选区读取所需的权限。此权限可以控制电脑，代码实际只查询前台应用焦点元素及其祖先的选中文字；仅对自己审阅和信任的构建授权。
3. 如果系统自带“朗读所选文本”也使用 ⌥Esc，请自行关闭或改它的快捷键，以免两个朗读器同时触发。App 不会代你修改设置。
4. 在系统设置 → 通用 → 语言与地区 → 翻译语言中，按系统提示下载英语（英国）和简体中文资源。普通词典可在 macOS“词典”App 中自行配置。
5. 在提供辅助功能选区的 App 中选中 `prompt`，按 ⌥Esc。首次模型加载和首次生成会慢一些。

菜单栏“读”可停止、重听、打开输入窗口或退出；关闭结果卡不等于退出 App。没有开机自动启动。

## 常见问题

- **需要配置声音**：检查四个配置字段、路径及权限；模型、Python 和参考音频都必须已存在。
- **没有读取到选区**：该 App 可能不提供辅助功能选区；可复制后手动粘贴到阅读器输入窗口。
- **仍提示权限**：本地临时签名重新构建后，macOS 可能不认旧授权。固定 App 位置，退出 App，再在系统设置移除旧记录、重新加入最新构建。每次是否授权由使用者决定。
- **快捷键注册失败**：检查其他 App 是否占用 ⌥Esc。
- **翻译不可用**：确认安装的是英语（英国）和简体中文，单词补充义项还取决于本机词典。
- **生成慢**：首次要加载模型，语音在生成完整音频后播放；它不是真正边生成边播放。每次最多 1500 个字符，长文本建议分段。
